# F5PI Backend Project

Backend of F5PI application, which allow users to manage their friendly football games, having count of their statistics (goals and results), players involved, fields and seasons.

## Overview

Technologies used:
  - Kotlin
  - Spring Boot 3
  - Spring Security 6
  - Spring Data JPA
  - JWT implementation
  - MySQL
  - Swagger

## Installation

Follow these steps to install and run the project:

  1. Clone the repository: `git clone https://github.com/EzeSosa/f5pi-backend.git`
  2. Navigate to the project directory: `cd your-repo`
  3. Build the project using Grade: `gradle build`
  4. Run the project: `gradle run`  /  `gradle bootRun`
  5. Test the API using Postman or another HTTP client at `http://localhost:8080`
